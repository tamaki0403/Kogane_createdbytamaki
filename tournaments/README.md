# 大会設定ファイル

このディレクトリは、既存のOTP方式（3〜4チーム予選総当たり＋A/Bリーグのシングルエリミネーション）を使う大会の設定を保存する。

大会を追加するときは、このチャットで要件を確認したうえでJSONを追加する。進行ロジックを大会ごとに複製しない。`active_operator_panel: true`の各大会は、大会IDを含む固有のボタンIDと専用Discordチャンネルを使い、Bot起動時にそれぞれ独立した運営パネルを登録する。

設定対象:

- 大会ID、名称、公開URL
- チーム人数、XP上限
- 予選形式（現在は3〜4チーム、A〜D表示、各組1・2位進出に限定）
- A/Bリーグ名、BO数
- 当日運営チャンネル、運営ロール、対戦カテゴリー
- ステージと公開ルール

スイスドロー、ダブルエリミネーションなど`otp_round_robin_single_elimination`以外の方式は、設定追加だけでは対応しない。既存コードを調査し、必要な進行ロジックを別途実装してからformatを追加する。

変更手順:

1. ユーザーから大会要件とDiscord ID群を受け取る。
2. 未定義ルールを確認する。
3. JSONを作成または更新する。
4. テストとチャンネル数の事前確認を行う。
5. 差分をユーザーへ提示する。
6. 明示的な許可後にデプロイする。
